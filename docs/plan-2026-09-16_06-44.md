# Plan — round report: hands, round bar, Markdown export (2026-09-16_06-44)

Status: implemented.

## Need

The round report is hard to read and hard to feed to an LLM.

1. Each table must show the **full hand before the play**.
2. Only **one round** on screen; pick it from a bar.
3. **Export Markdown** of the whole match, compact and unambiguous for an LLM.

## Data

`DuelRecord` stores `leftHand` / `rightHand` (and infected flags) snapped before `pickRandomPlay`. Byes store the same.

## UI

Round buttons `1 … N`, default = newest after each Play. Each seat: available hand (thumbs) then the played pile.

## Export format (`zh-md/1`)

Short tokens, one table = a few lines, no images.

- Pip card: `AS` `2H` `10C` (Ace of spades, 2 of hearts). Ace = 1. No J/Q/K.
- Specials spelled: `shot` `zombie` `vax` (so `S` is never shotgun).
- Faction: `H` human, `Z` infected, `X` eliminated.
- Header: schema, seed, rounds, verdict.
- Each table: both pre-hands, play, totals, outcome, taken card.
- Close with a final roster.

Download `zh-s{seed}-r{n}.md`. Copy to clipboard when the browser allows it.

## Review

KISS: one exporter, one selected round. YAGNI: no replay slider, no JSON. SRP: export stays out of `match.ts`.
